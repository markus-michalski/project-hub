## Field Guide

**name** *(required)*: Engagement name — e.g. `Acme Corp — Strategy Review`
**description**: What is the consulting scope? What is the deliverable?
**phase**: Current phase — `Scoping` | `Analysis` | `Design` | `Delivery` | `Closed`
**go_live**: Project end / delivery date — e.g. `"2026-08-31"`
**budget**: Engagement value (optional) — e.g. `€25.000` or `15 PT`
**notes**: Client name, sub-contractors, special requirements
