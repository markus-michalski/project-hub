## Field Guide

**name** *(required)*: Short, unique project name — e.g. `Q3 Website Relaunch`
**description**: What is this project about? What is the goal?
**phase**: Current status — e.g. `Discovery`, `Planning`, `Execution`, `Closed`
**go_live**: Target completion date — e.g. `2026-12-31` or `Q4 2026`
**budget**: Budget (optional) — e.g. `€50.000` or `50 PT`
**notes**: Internal notes, constraints, special requirements
