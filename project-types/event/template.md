## Field Guide

**name** *(required)*: Event name — e.g. `Q3 All-Hands 2026`
**description**: What kind of event? What is the purpose?
**market**: Location / region — e.g. `Berlin`, `Amsterdam`, `Online`
**phase**: Current phase — `Planning` | `Preparation` | `Promotion` | `Execution` | `Follow-up`
**go_live**: Event date — e.g. `"2026-09-15"`
**budget**: Event budget (optional)
**notes**: Venue, expected attendees, special requirements
