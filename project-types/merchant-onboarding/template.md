## Field Guide

**name** *(required)*: Merchant name — e.g. `Acme Corp DE`
**description**: Short project description
**market** *(required)*: Target country/market — e.g. `DE`, `DE, AT, CH`, `NL`
**products** *(required)*: Riverty products to integrate — e.g. `BNPL 30d, Pay in 3, Direct Debit`
**phase**: Current onboarding phase — `Discovery` | `Contract` | `Tech Integration` | `UAT` | `Go-Live` | `Hypercare`
**go_live**: Target go-live date — e.g. `"2026-06-30"` or `Q4 2026`
**budget**: Budget (optional)
**notes**: PSP partner, internal notes, special requirements
